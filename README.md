# grand-cinema-docs

Dépôt de pilotage du projet **« Le Grand Cinéma »**, plateforme web de réservation de billets réalisée dans le cadre du titre professionnel **Concepteur Développeur d'Applications (CDA, niveau 6)** — Bachelor Développeur d'Application, Studi.

---

## 🎯 Rôle de ce dépôt

Ce dépôt porte le **backlog produit** du projet : les EPICs et les user stories sont des issues GitHub de ce dépôt, suivies dans le [Project n° 3](https://github.com/orgs/Grand-Cinema-Studi/projects/3).

- Une user story décrit un besoin métier, souvent réalisé à la fois dans le backend et dans le frontend : elle vit ici, indépendamment du code.
- Les tâches techniques vivent dans les dépôts de code (`grand-cinema-backend`, `grand-cinema-frontend`), rattachées à leur user story comme sous-issues.

La documentation technique (installation, base de données, API, convention de branches) se trouve dans le dépôt backend, à côté du code qu'elle décrit.

## 🎬 Contexte du projet

« Le Grand Cinéma » est un cinéma historique (50+ ans, **10 salles modulables, 1 700 places**) dont le fonctionnement est encore entièrement physique. Lors des pics d'affluence — notamment pendant le **Festival de Jazz** — les files d'attente dépassent 30 minutes, des spectateurs abandonnent leur achat et le remplissage des salles est mal optimisé.

**Objectif business** : +30 % de fréquentation sur 12 mois grâce à une plateforme de réservation en ligne.

**Profils utilisateurs identifiés** : Spectateur régulier · Festivalier / Touriste · Caissier · Contrôleur · Responsable Programmation / Direction.
