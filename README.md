# grand-cinema-docs

Documentation de conception et de pilotage du projet **« Le Grand Cinéma »**, plateforme web de réservation de billets réalisée dans le cadre du titre professionnel **Concepteur Développeur d'Applications (CDA, niveau 6)** — Bachelor Développeur d'Application, Studi.

> 📌 Ce dépôt est **évolutif** : il est complété au fur et à mesure de l'avancement des Blocs 1, 2 et 3. Les sections marquées _À venir_ seront renseignées progressivement.

---

## 🎯 Rôle de ce dépôt

Ce dépôt centralise **tous les livrables documentaires** du projet (hors code source applicatif) :

- la **conception et la spécification** de la solution (Bloc 1) ;
- la **gestion, le pilotage et le testing** du projet (Bloc 2) ;
- la **documentation technique** accompagnant le développement (Bloc 3) ;
- les supports des **soutenances vidéo** et des réponses aux évaluateurs.

Il sert de référence unique et versionnée pour le jury, et de source pour les dépôts officiels sur la plateforme Studi.

## 🎬 Contexte du projet

« Le Grand Cinéma » est un cinéma historique (50+ ans, **10 salles modulables, 1 700 places**) dont le fonctionnement est encore entièrement physique. Lors des pics d'affluence — notamment pendant le **Festival de Jazz** — les files d'attente dépassent 30 minutes, des spectateurs abandonnent leur achat et le remplissage des salles est mal optimisé.

**Objectif business** : +30 % de fréquentation sur 12 mois grâce à une plateforme de réservation en ligne.

**Profils utilisateurs identifiés** : Spectateur régulier · Festivalier / Touriste · Caissier · Contrôleur · Responsable Programmation / Direction.
